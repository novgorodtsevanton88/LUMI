# LUMI

Безкоштовний цифровий помічник для батьків дітей від народження до 5 років: облік і прогноз сну, білий шум, фізичний розвиток із перцентилями ВООЗ, медичний календар і щеплення, розвивальні ігри, щоденник і сімейна синхронізація. Без підписок, реклами та платних модулів; працює офлайн.

Статус: **Фаза 0 (проєктування) завершена.**

- [Технічне завдання](docs/TZ.md)
- [Технічний план Фази 0](docs/phase-0.md)
- [Схема бази даних](supabase/migrations/0001_lumi_schema.sql) і [сценарії перевірки RLS](supabase/tests/rls_scenarios.sql)

Стек: React, TypeScript, Vite, Tailwind CSS, Supabase (PostgreSQL, Auth, Storage, Realtime), IndexedDB (Dexie), PWA.
